# Проект "банковские операции"

## Описание:

Проект " банковские операции" - это приложение на Python, 
которое работает с банковскими операциями.

## Примеры использования функций:

+ Модуль masks
содержит функции для создания масок на номер карты и счета:

**get_mask_card_number**

Принимает на вход номер карты в виде числа и возвращает маску номера вида XXXX XX** **** XXXX где ХХХХ номер карты

**get_mask_account**

Принимает на вход номер счета и возвращает маску номера вида **XXXX где ХХХХ последние четыре цифры счета


+ Модуль widget
содержит функции для работы с банковскими данными:

**mask_account_card**

Принимает  строку, содержащую тип и номер карты или счета, и возвращает строку с замаскированным номером.

    Пример: "Visa Platinum 8990922113665229" → "Visa Platinum  8990 92** **** 5229"

**get_date**

Принимает на вход строку с датой в формате "2024-03-11T02:26:18.671407"
и возвращает строку с датой в формате "ДД.ММ.ГГГГ" ("11.03.2024").

      
+ Модуль processing
содержит  функции для фильтрации и сортировки банковских операций:

**filter_by_state**

Фильтрует список операций по статусу выполнения (например по 'EXECUTED')

      
**sort_by_date** 

Сортирует список операций по дате убывания или возрастания при помощи True или False
